# Customer Churn Analysis

## Project Overview
This project explores customer transaction data to understand purchasing behavior and identify patterns associated with customer churn.

## Objectives
- Analyze customer churn distribution.
- Compare purchasing behavior between churned and non-churned customers.
- Explore cart abandonment, website engagement, and membership duration.
- Identify actionable insights and customer retention opportunities.

## Tools & Technologies
- Python
- Pandas and NumPy
- Plotly
- Jupyter Notebook

## Key Findings
- Overall customer churn rate: 10.9%.
- Churned customers have a lower average purchase frequency.
- Cart abandonment is higher among churned customers.
- Churned customers show lower website engagement and spending scores.

## Business Recommendations
- Investigate potential barriers in the checkout experience.
- Explore initiatives to encourage repeat purchases.
- Validate observed churn patterns before treating them as causes.

## Project Status
Exploratory data analysis completed. Interactive dashboard development and presentation are planned next.
